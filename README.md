# Atmos Dashboard

Atmos Dashboard je napredna Smart Dashboard i PWA aplikacija koja objedinjuje internet pretragu, vremensku prognozu, kalendar, planer, radio, kalkulator, beleške i druge korisne alate u jednom modernom interfejsu.

Aplikacija je dizajnirana kao centralna početna stranica za svakodnevni rad na računaru, telefonu ili tabletu i predstavlja odličnu zamenu za klasične home stranice prepune reklama i nepotrebnog sadržaja.

## Pregled modula i alata

### Internet pretraga
Ugrađena pretraga omogućava brzo pretraživanje interneta direktno iz dashboard-a. Podržan je izbor različitih pretraživača bez otvaranja dodatnih stranica.

### Vremenska prognoza
Prikazuje trenutnu temperaturu, vremenske prilike, vlažnost vazduha, brzinu vetra i višednevnu prognozu za željeni grad.

### Planer zadataka
Ugrađeni Task Planner omogućava dodavanje zadataka, evidenciju obaveza, praćenje realizacije i brisanje završenih zadataka.

### Kalendar
Praktičan mesečni kalendar za pregled datuma i organizaciju ličnih obaveza, poslovnih sastanaka i planiranje događaja.

### Alarm
Sadrži ugrađeni alarm sa mogućnošću podešavanja vremena, aktivacije i otkazivanja, pogodan za podsetnike tokom rada.

### Beleške
Omogućava čuvanje kratkih tekstualnih beleški direktno na dashboard-u za brze napomene, podsetnike i ideje.

### Kalkulator
Ugrađeni kalkulator omogućava osnovne matematičke operacije, rad preko tastature i brza računanja bez dodatnih aplikacija.

### Online radio i medija plejer
Omogućava slušanje internet radio stanica jednim klikom i reprodukciju multimedijalnih sadržaja direktno iz samog dashboard-a.

### Foto-slajder
Prikazuje fotografije kroz ugrađeni slajder — pogodno za lične galerije, inspirativne fotografije ili rotirajući sadržaj.

### Brzi linkovi
Omogućava organizaciju omiljenih sajtova i servisa (GitHub, Gmail, Outlook, YouTube, Copilot, ChatGPT, Google Drive, poslovni portali).

## PWA podrška i instalacija

Atmos Dashboard koristi Progressive Web App tehnologiju.

**Prednosti:**
- Instalacija bez App Store-a
- Pokretanje kao desktop aplikacija
- Brže učitavanje
- Offline podrška
- Automatska ažuriranja

### Android
1. Otvoriti dashboard u Chrome pregledaču.
2. Izabrati "Install App".
3. Potvrditi instalaciju.

### Windows
1. Otvoriti dashboard u Chrome ili Edge pregledaču.
2. Kliknuti "Install".
3. Potvrditi instalaciju.

### iPhone / iPad
1. Otvoriti dashboard u Safari pregledaču.
2. Izabrati Share.
3. Kliknuti "Add to Home Screen".
