ATMOS DASHBOARD

Atmos Dashboard je napredna Smart Dashboard i PWA aplikacija koja objedinjuje internet pretragu, vremensku prognozu, kalendar, planer, radio, kalkulator, beleške i druge korisne alate u jednom modernom interfejsu.

Aplikacija je dizajnirana kao centralna početna stranica za svakodnevni rad na računaru, telefonu ili tabletu i predstavlja odličnu zamenu za klasične home stranice prepune reklama i nepotrebnog sadržaja.

Live Demo:
https://gembirdt-bit.github.io/atmos/

SMART HOME STRANICA BEZ REKLAMA

Atmos Dashboard može se koristiti kao početna stranica internet pregledača.

Za razliku od standardnih home stranica koje prikazuju:

• Reklame
• Sponzorisani sadržaj
• Nepotrebne vesti
• Promovisane članke

Atmos Dashboard nudi:

• Čist i pregledan interfejs
• Potpunu kontrolu nad sadržajem
• Brz pristup omiljenim alatima
• Fokus na produktivnost
• Bez reklama
• Bez nepotrebnih informacija

Idealan je kao:

• Početna stranica pregledača
• Nova kartica (New Tab)
• Lični portal
• Poslovna kontrolna tabla
• Organizator svakodnevnih aktivnosti
